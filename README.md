# Titanic_Survivor-_prediction_Machine_Learning
🚢 Titanic Survivor Prediction

📌 Project Overview

A Machine Learning project focused on preparing Titanic passenger data for survival prediction using Python.

❗ Problem Statement

Predict whether a Titanic passenger survived or not based on passenger information such as age, gender, passenger class, and ticket fare.

💡 Proposed Solution

Develop a data preprocessing pipeline to clean and transform raw passenger data into a format suitable for Machine Learning.

🎯 Key Features

- Data loading and validation
- Data cleaning and preprocessing
- Handling missing values
- Categorical encoding
- Train-test splitting
- Feature scaling

🛠️ Technologies Used

- Python
- Pandas
- Seaborn
- Scikit-learn
- Jupyter Notebook
